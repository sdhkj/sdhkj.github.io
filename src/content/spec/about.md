# 关于

这里是 **sdhkj 的博客**，一个用 [Astro](https://astro.build/) + [Fuwari](https://github.com/saicaca/fuwari) 搭建的静态博客，用 [Sveltia CMS](https://sveltiacms.app/) 在线写作，部署在 GitHub Pages 上。

## 这个站点

- 内容以 Markdown 保存在 GitHub 仓库 [sdhkj/sdhkj.github.io](https://github.com/sdhkj/sdhkj.github.io) 里
- 写作入口：<https://sdhkj.github.io/admin/>
- 文章、页面、站点设置（站名、签名、头像、主题色）都可以在后台改，改完自动发布
